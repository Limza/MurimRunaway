## 2. 우선순위 — 본 Phase에서 채울 항목

### 2.1 재능 포트레이트 3종 (M8) ★ 본 Phase 최우선

**왜 격상되는가**:
- 인물 일러스트는 아이콘보다 수정 루프가 훨씬 길다 (한 캐릭터당 시안 5~8장 + 톤 보정 3~4회).
- M8(Phase 8) 진입 전에 톤이 확정돼 있어야 본 Phase의 다른 작업과 병행 가능.
- 옵나 차별점인 **재능 시스템**의 시각적 자산이라 v4 정체성에 직결.

**완성형 프롬프트** — [Phase_1_AssetQueue.md §4.3](Phase_1_AssetQueue.md)의 천무지체/카피/대종사 프롬프트를 그대로 사용.

| 슬롯 | 상태 | 시안 | 메모 |
|------|------|------|------|
| 천무지체 (天武之體) | [ ] | 0/N | 신성·후광. 정좌 자세 |
| 카피 (외부 기술 학습형) | [ ] | 0/N | 그림자·반사. 다중 자세 |
| 대종사 (大宗師 / 일관형) | [ ] | 0/N | 무게감·노련함. 도복 |

**작업 순서 권장**: 천무지체부터 — 가장 단순한 도상(정좌 자세 + 후광)이라 톤 기준점 잡기 좋음. 다음 대종사(노숙한 도복 인물), 마지막 카피(잔상·그림자 표현으로 가장 까다로움).

**Phase 2 동안 목표**:
- 각 재능별 시안 **최소 1장 확보**.
- 톤이 마음에 들면 같은 대화에서 1~2회 보정.
- 최종 픽은 M8 진입 시점에 다시 검토 (지금은 후보 수집).

| 변형 | 상태 | 메모 |

## 3. 작업 사이클

[Phase_1_AssetQueue.md §5](Phase_1_AssetQueue.md)와 동일.

특히 재능 포트레이트는:
1. 천무지체 첫 시안 → "양피지 톤 + 수묵 먹선" 기준 확립.
2. **같은 대화 안에서** 대종사·카피로 이어 생성 → 톤 일관성 자동 확보.
3. 세션을 끊고 새로 시작하면 톤이 흔들리므로 **세 인물을 한 세션에 모은다**.
