# 마일스톤 (Milestones) — 모바일 오토배틀 로그라이트 (v4)

> **본 문서의 위상**
> - 정식 게임의 **진행 추적용 마일스톤**. 일정이 아닌 **순서·상대 부담** 기록.
> - 의존: [BATTLE_DESIGN.md](BATTLE_DESIGN.md) (Phase 정의·Acceptance, v4 갱신본), [ASSET_PIPELINE.md](ASSET_PIPELINE.md) (에셋 생성 절차).
> - 레퍼런스: 옵시디언 나이트 (ActFirst Games) — 오토배틀 + 레벨업 카드 드래프트 + 메타 진행.
> - **차별점**: 옵나 셸 + 무림 **재능 시스템(카피/대종사/천무지체)** + **보스전 한정 수싸움**(강공/오의 매트릭스).

> **작성 규칙**
> - 캘린더 일정 금지 (시간 단위 비고정 솔로 개발). 부담은 S/M/L 상대 표기.
> - Phase 진입 조건: 직전 Phase의 모든 Acceptance + 컴파일 + 커밋.
> - 변경은 §7 변경 이력에 한 줄 추가.

## 1. 전제 (Constraints)

- **솔로 개발, 시간 단위 비고정** — "시간 날 때마다" 진행. 캘린더 견적 금지.
- **에셋은 모두 AI 생성** — 자작·외주 없음. 도구·워크플로는 [ASSET_PIPELINE.md](ASSET_PIPELINE.md).
- **모바일 세로 우선** — Android 빌드 우선, iOS는 v1.0 이후.
- **Placeholder 우선** — Phase 0~10까지 색+텍스트 placeholder. 실에셋은 M11(모바일 UI) 진입 직전부터.
- **MVP 범위**: 캠페인 + 비동기 PvP(리더보드). **컷**: 클랜·협동보스·가챠·라이브옵스.
- **백엔드 최소화** — 비동기 PvP는 단일 리더보드만(서버리스 BaaS).
- **한 Phase = 한 커밋 단위** — Acceptance 미달 상태로 다음 Phase 코드 시작 금지.

- **Done**: P2 Acceptance 3개.

  - 적 패턴 hint 표시 아이콘 3종 (직공·연환공·허실공) — §4.1
  - 매치업 결과 피드백 (Counter ★ / Normal / Weak ✗) — §4.4
- **Done**: P5 Acceptance 5개 + 보스 1체 시연(보스 등장 → 강공 차징 → 5택 → 매치업 결과 → 보스 stunned 또는 플레이어 피해).

- **에셋**:
  - 재능 포트레이트 3 (천무지체·카피·대종사) — §4.2
  - 재능 선택 화면 레이아웃 — §4.4
- **Done**: P8 Acceptance 3개 + 같은 스테이지를 3재능으로 플레이 시 빌드가 다르게 형성되는지 1회 검증.

- **에셋**: UI 키트 풀세트, 한국어 폰트, 화면별 레이아웃 6~8종.
- **Done**: Android 실기기에서 한 런 풀 플레이 → 메타 화면까지 끊김 없음.
