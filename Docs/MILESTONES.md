## 1. 전제 (Constraints)

- **솔로 개발, 시간 단위 비고정** — "시간 날 때마다" 진행. 캘린더 견적 금지.
- **에셋은 모두 AI 생성** — 자작·외주 없음. 도구·워크플로는 [[ASSET_PIPELINE]].
- **모바일 세로 우선** — Android 빌드 우선, iOS는 v1.0 이후.
- **Placeholder 우선** — Phase 0~10까지 색+텍스트 placeholder. 실에셋은 M11(모바일 UI) 진입 직전부터.
- **MVP 범위**: 캠페인. **컷**: 클랜·협동보스·가챠·라이브옵스, **비동기 PvP**(v4.1, v1.1+ 보류 — §5 참조).
- **한 Phase = 한 커밋 단위** — Acceptance 미달 상태로 다음 Phase 코드 시작 금지.
- **에셋·코드 트랙 병렬 진행** — AI 이미지 생성 대기로 코드가 멈추지 않도록, 코드 Phase는 placeholder로 Acceptance 통과 가능. 실에셋은 별도 트랙에서 비동기로 작업·교체하며, 에셋 교체는 코드와 분리된 커밋으로 남긴다. 트랙 구성은 §3 참조.

### 3.1 에셋 트랙 (코드와 병렬 진행)

AI 이미지 생성 대기시간이 길어 코드 Phase의 직렬 진행을 막는다. 코드는 placeholder로 Acceptance를 통과시키고, 에셋은 아래 3트랙에서 **비동기로 큐잉**해 도착 시 교체 커밋한다.

| 트랙 | 범위 | 큐잉 시작 | 코드 통합 시점 |
|------|------|-----------|----------------|
| **A. 전투 아이콘** | 방어 4택·강공 차징·hint·매치업 피드백·오의 3택·재능 포트레이트 3 | M3 진입 시점 | M5/M6/M8 도착 시 교체 |
| **B. UI·배경** | 스테이지 배경, UI 키트, 한국어 폰트 검토, 화면 레이아웃 6~8종 | M10 진입 시점 | M11/M14 도착 시 교체 |
| **C. 캐릭터·장비 외형** | 기본 캐릭터 리깅용 분리 PSD, 슬롯별 어태치먼트(검·옷·신발·머리) | M8 진입 시점 | M13 진입 시 필수 |

> [!note] 트랙 C 전제
> Unity 2D Animation(뼈대 + 어태치먼트) 방식 전제. 검 1종 = 정지 이미지 1장. 상세는 M13 본문.

### M13 — Phase 13 메타 진행 + 외형 ★ v4 신규, 부담 격상 (L / L)
- **코드**:
  - `Inventory`, `Equipment` (슬롯 6종: 외형 슬롯 4 + 스탯 슬롯 2), `PermanentUpgrade` (MaxHP·기본 공격력 등 영구 스탯), 골드/재화.
  - **외형 시스템**: Unity 2D Animation(무료) 기반. 기본 캐릭터를 본(bone)으로 분리하고, 슬롯별 어태치먼트를 bone에 attach. 검 1종 = 정지 이미지 1장이면 모든 모션에 자동 추종.
  - **슬롯 구성**:
    - 외형 반영: 검 / 옷 / 신발 / 머리(삿갓·비녀·영웅건·투구)
    - 스탯 전용: 반지 / 목걸이 (외형 영향 없음, 아이콘만)
- **에셋**:
  - 기본 캐릭터 분리 PSD 1세트 (상체·하체·팔·손 분리 — 리깅용)
  - 외형 슬롯 어태치먼트: 슬롯당 v1.0 기준 4종 × 4슬롯 = 16장 (검·옷·신발·머리 각 4종)
  - 스탯 슬롯 아이콘: 반지·목걸이 각 4종 = 8장
  - 장비 인벤토리/장착 화면 UI (M14에서 통합)
- **WHY 부담 격상**: Unity 2D Animation 초기 리깅 1회(S~M) + 슬롯별 z-order/오프셋 정의 + 외형 미리보기 코드. v3 SSOT의 단순 슬롯제 대비 외형 반영으로 코드·에셋 모두 L.
- **Done**:
  - 런 종료 후 획득물 인벤토리 반영 → 강화 → 다음 런 통계 차이 확인.
  - 검·옷·신발·머리 각 1종 이상 장착·해제 시 캐릭터 외형이 즉시 바뀌고 전투 모션에서 함께 움직임.
