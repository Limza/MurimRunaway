> **본 문서의 위상**
> - 정식 게임의 **게임 디자인 SSOT (비전·콘텐츠·시스템 개요)**.
> - 시스템별 코드 명세는 별도 TDD 문서가 갖는다 (예: 전투 시스템). 본 문서는 그 시스템들을 한 곳에서 조망한다.
> - [GAME_DESIGN.md](GAME_DESIGN.md)는 **프로토 시기 SSOT로 동결** — 본 문서가 정식 게임의 SSOT다. 둘이 충돌하면 본 문서 우선.

## 1. 한 줄 컨셉 (Elevator Pitch)

> **추격당하는 무림인이 학습한 무공으로 자동 응전하면서, 매 단계 빌드를 키우고 5분파의 갈림길을 점진적으로 결정해가는 PC용 무협 디펜스 로그라이트.**

자동 전투의 흐름 위에 **수싸움(Mind-Game)** 두 갈래(방어 선택지 / 오의 공격 선택지)가 결정의 밀도를 만든다. 한 런 10~15분, Steam 가로 화면, 마우스+키보드.

---

## 2. 디자인 필러 (Design Pillars)

모든 시스템은 아래 셋 중 적어도 하나를 직접 지지해야 한다. 어디에도 닿지 않는 시스템은 만들지 않는다.

| # | 필러 | 의미 |
|---|------|------|
| **P1** | **흐름 위의 결정** | 평시는 자동 시전이 흘러가게 두고, 강공·오의 같은 결정적 순간에만 수동 결단을 요구한다. 손이 바쁜 게임이 아니라 **눈과 머리가 바쁜 게임**. |
| **P2** | **읽기 vs 도박** | 적의 의도를 읽으면 카운터 한 방, 못 읽으면 안전한 절반 데미지. 운이 결과를 좌우하지 않고 **정보(오성)와 빌드**가 좌우한다. |
| **P3** | **다른 길, 다른 결말** | 재능·분파·경로의 변주가 매 런 다른 모양을 만든다. 같은 콘텐츠도 **누구로, 어느 분파로 가는가**에 따라 다르게 펼쳐진다. |

## 3. 플레이어 경험 목표

### 3.1 정서 곡선
| 시점 | 기대 정서 |
|------|----------|
| 한 전투 (~30초) | 초반 안정 → 강공 위협의 긴장 → 오의 한 방의 카타르시스 |
| 한 런 (~12분) | 도망자의 절박함 → 빌드가 굳어지는 안도 → 보스·결말의 의미부여 |
| 두 번째 런 | "이번엔 다른 재능·다른 분파" — 변주 욕구 |
| 다섯 번째 런 | 빌드 조합·분파 조합의 깊이 발견 |

### 3.2 안티-골 (만들지 않을 경험)
- 손이 바쁜 액션 — DPS 체크·콤보 입력은 전투의 본질이 아니다.
- RNG가 결과를 100% 결정 — 패배 시 "내가 졌다"가 아니라 "운이 없었다"가 되는 패턴.
- 동일 빌드 강제 — 빌드 다양성이 사실상 한 정답 트리로 귀결되는 패턴.
- 끝없이 늘어지는 한 런 — 15분 안에 결말이 나야 한다.

## 4. 핵심 루프

### 4.1 분 단위 (전투 1판)
```
적 진군 → 자동 시전 + 적 일반공격 ↻
   │
   ├─ 적 강공 차징 → [방어 5택]   → 매트릭스 판정 → 결과 → 복귀
   └─ 플레이어 오의 발동 → [공격 3택] → 매트릭스 판정 → 결과 → 복귀
   │
   적 전멸 → 클리어 / 플레이어 HP=0 → 패배
```

### 4.2 스테이지 단위 (전투 ~ 보상 ~ 분기)
```
전투 클리어 → 보상 3택(학습/강화/능력) → 다음 경로 2~3택 → 다음 스테이지
```

### 4.3 런 단위 (시작 ~ 결말)
```
재능 선택 → 시작 무공 3 → 15스테이지 진행 → 보스 → 분파 종료 분기 → 결말
```

### 4.4 메타 루프
정식 게임은 **메타 성장 없음**을 기본으로 한다 (모든 런이 동일 시작 조건). 잠금 해제식 메타가 필요한지는 출시 후 데이터 기반으로 재검토. → §12 (검토 중) 참조.

## 5. 시스템 개요

### 5.1 전투 시스템 (Battle)
오토 디펜스. 학습한 무공이 거리·쿨·내공 조건에 따라 자동 시전된다. 적의 강공 차징 시점에 방어 수싸움(5택), 플레이어 오의 핫키 시점에 공격 수싸움(3택). 양쪽 모두 **3×N 상성 매트릭스**가 결과를 결정. 자원은 HP / 내공 / 기세 / 오성 / 회피율 5종.

### 5.2 무공 시스템 (Skills)
4분류 — **초식**(능동 공격) / **심법**(패시브 버프) / **경공**(이동·회피) / **오의**(기세 소비 결정타). 시작 슬롯 3, 최대 6. 같은 무공 두 번 학습 시 자동 강화. 무공은 ScriptableObject 데이터.

### 5.3 보상 시스템 (Rewards)
스테이지 클리어마다 3중 1 선택. 카테고리는 **무공 학습 / 무공 강화 / 능력 상향** 셋. 재능별로 후보 풀 비중이 다름(천무지체=균형, 카피=학습 위주, 대종사=강화 위주).

### 5.4 경로·맵 (Run Path)
Slay the Spire 축소판. 매 스테이지 클리어 후 다음 후보 2~3개. 각 후보는 (a) 타입(전투/엘리트/기연), (b) 분파 색을 표시. 일부 후보는 분파 정렬 조건을 만족해야 잠금 해제.

### 5.5 기연 이벤트 (Encounters)
전투 없는 만남. 텍스트 + 2~3 선택지. 결과는 **무공 학습 / 능력 변화 / 분파 정렬 변화** 중 하나 이상. 분파 정렬에 따라 만남 풀이 달라진다.

### 5.6 분파 정렬 (Faction Alignment)
5분파(귀환=정파/마교/개방/소림/은퇴)에 대한 정렬 점수 0~100 누적. 행동·경로·기연이 점수에 누적 영향. 종료 분기 5택의 활성 조건이 됨.

### 5.7 재능 (Talents)
런 시작 시 1개 선택. 시작 무공·시작 자원·특수 능력이 다름. 정식 게임 출시 범위 = **천무지체 / 카피 / 대종사 3종**.

### 5.8 적 시스템 (Enemies)
**행동 결정론 + 명시적 RNG 예외 두 곳** — 일반 공격·강공 사이클·진군은 결정론, 강공 종류 풀(`attackPatterns`)·오의 방어 풀(`defensePatterns`)만 매 발생 시 풀에서 RNG 1개. 이 예외가 수싸움(오성 hint)의 의미를 만든다. 보스는 페이즈별로 다른 풀.

### 5.9 보스 (Boss)
스테이지 15 고정. 추격대장 3페이즈, 페이즈마다 강공·방어 풀이 변경되어 빌드 검증의 마지막 관문 역할.

### 5.10 결말 분기 (Endings)
보스 클리어 후 분파 5택. 정렬 점수에 따라 일부 강조/잠금. 정식 게임은 **결말 텍스트 + 결말 일러스트 1장**으로 차별화 (메타 보너스는 §12 검토 중).

## 6. 콘텐츠 카탈로그

### 6.1 무공 (Skill) — 출시 풀 목표 30~40종
프로토 15~20종에서 정식 출시까지 30~40종으로 확장. 4분류 비중 목표:

| 분류 | 정식 비중 (대략) | 역할 |
|------|------------------|------|
| 초식 | ~50% (15~20종) | 주 공격원, Close/Mid/Far 균등 |
| 심법 | ~20% (6~8종) | 패시브 버프 — 빌드 정체성 형성 |
| 경공 | ~15% (4~6종) | 회피·이동, HP 30% 트리거 보장 회피 포함 |
| 오의 | ~15% (5~7종) | 기세 소비 결정타, 단일/다수/전체 타게팅 |

프로토 무공 13종 (태인장·낙뢰신권·천하삼십육검·유운검법·홍단서천·난화지·비연신법·무염십팔보·태을신공·현청건곤강기·검정중원·낙하구구검·삼락검)을 출발점으로, 분파 색을 더한 신규 무공으로 확장.

### 6.2 적 (Enemy) — 출시 풀 목표 8~10종 + 보스 1
프로토 4종(잡적·자객·무림고수·추격대장 보스)에서 확장:

| 티어 | 등장 | 종 |
|------|------|----|
| 잡적 | 1~10 스테이지 | 산적, 추격병, 정찰병 (3종 목표) |
| 정예 | 4~14 | 자객, 검수, 권사 (3종 목표) |
| 엘리트 | 6~14 | 무림 고수, 분파 호위 (2종 목표) |
| 보스 | 15 | 추격대장 (3페이즈) |

> 분파별 적 풀(예: 마교 자객은 마교 정렬 경로에서 등장)은 정식 출시 범위 [검토 중] (§12).

### 6.3 분파 (5종)
| 분파 | 정렬 키워드 | 종료 분기 의미 |
|------|------------|---------------|
| 귀환 (정파 복귀) | 명예·복수·정의 | "본 사문으로 돌아가 누명을 벗는다" |
| 마교 투항 | 흑도·실리·강함 | "추격에 지쳐 흑도로 돌아선다" |
| 개방 합류 | 자유·정보·도주 | "떠돌이 거지 행세로 자유를 얻는다" |
| 소림 입문 | 불도·평정·은신 | "속세를 떠나 불문에 귀의한다" |
| 은퇴 | 무공 봉인·평민 | "모든 무공을 봉인하고 평민으로 산다" (항상 가능) |

### 6.4 기연 이벤트 — 출시 풀 목표 15~20종
프로토 5~10종에서 확장. 분파별 5종 정도 + 분파 무관 5종.

| 분파 | 기연 (예) |
|------|----------|
| 마교 | 마교 자객, 흑도 상인 |
| 정파 | 정파 노승, 사문 사형제 |
| 소림 | 소림 승려, 노스님의 차 |
| 개방 | 개방 거지, 정보꾼 |
| 무관 | 은거기인, 추격대장 부하, 비급 발견 |

### 6.5 재능 (Talent) — 출시 범위 3종
| 재능 | 한 줄 | 시작 오성 | 시작 기세 | 시작 무공 풀 (방향) | 특수 |
|------|------|----------|----------|-------------------|------|
| 천무지체 | 타고난 무인, 모든 면에서 평균 이상 | 8 (High) | 0 | 균형형 (초식·심법·오의 골고루) | 단계 보상 4택 (1개 더 보임) |
| 카피 (絶對的記憶) | 한 번 본 무공은 잊지 않는다 | 3 (Low — 정보 핸디캡) | 0 | 학습 위주, 시작 슬롯 비중 적음 | 적 무공을 확률 카피 (전투 중 학습) |
| 대종사 | 한 무공을 극한까지 다듬는다 | 6 (Mid) | 5 (첫 턴부터 오의 가능) | 강한 오의 + 초식 1 | 무공 강화 시 추가 효과 |

### 6.6 자원 (Resource) — 5종
HP / 내공(Energy) / 기세(Momentum) / 오성(Wisdom 1~10) / 회피율(Dodge%). 자원의 정확한 변화 룰은 [BATTLE_DESIGN.md](BATTLE_DESIGN.md) 참조.

## 7. 진행 구조 (Run Structure)

### 7.1 한 런 = 15스테이지
- 일반 전투 12~13개
- 엘리트 1~2개 (스테이지 5·10 부근)
- 보스 1개 (스테이지 15 고정)

### 7.2 스테이지 타입
| 타입 | 내용 |
|------|------|
| 전투 | 일반 적 4~5명 (최대 10) |
| 엘리트 | 강한 단일/소수 적, 보상 풀 품질↑ |
| 기연 | 전투 없음, 텍스트 선택지, 보상 비전투형 |
| 보스 | 스테이지 15, 추격대장 3페이즈 |

### 7.3 경로 분기 (Slay the Spire 축소판)
매 스테이지 클리어 시 다음 후보 2~3개. 후보별 (타입, 분파 색) 표시. 분파 정렬 조건이 달린 후보는 조건 미달 시 잠금.

### 7.4 보상 카테고리 (Reward 3중 1)
| 카테고리 | 내용 |
|---------|------|
| 무공 학습 | 새 무공 슬롯에 추가 (또는 슬롯 가득찼으면 교체 옵션) |
| 무공 강화 | 보유 무공 1개 +1Lv (효과 +50%) |
| 능력 상향 | HP/내공/기세/오성/회피율 중 하나 영구 +α (현 런 한정) |

### 7.5 페이스 목표
한 런 10~15분 — 한 스테이지 평균 30~60초 (전투 ~30초 + 보상·이동 ~10초 + 가끔 기연 ~30초).

## 8. 분파 정렬 시스템

### 8.1 정렬 점수
플레이어는 무소속으로 시작. 매 행동·경로·기연이 5분파 정렬 점수(각 0~100)에 누적 영향.

| 행동 | 영향 (예) |
|------|----------|
| 마교 무공 사용/학습 | 마교 +α |
| 정파 기연 / 사문 경로 | 귀환 +α |
| 소림 차·자비 선택 | 소림 +α |
| 도망·정보 거래 | 개방 +α |
| 무공 사용 자제·방어 위주 | 은퇴 +α |

수치는 [검토 중] — 한 런 안에 한두 분파만 30점 임계를 넘기도록 튜닝.

### 8.2 정렬의 영향
- 경로 분기 후보의 활성 조건 (예: 마교 기연은 마교 ≥ 30)
- 종료 분기 5택의 활성 조건 (분파 ≥ 30)
- 일부 기연의 만남 풀
- 정식 출시 범위에서 추가될 가능성: 분파 색 무공 보상 풀 가중치 (§12 검토 중)

### 8.3 종료 분기
보스 클리어 후 5택 화면. 정렬 점수가 높은 분파가 강조 표시. **은퇴**는 정렬 무관 항상 가능 (default fallback). 결과는 결말 텍스트 + 결말 일러스트 1장.

## 9. 비주얼·아트 디렉션

### 9.1 정식 게임 아트 방향
- **2D UI 기반**, 가로 화면 (16:9)
- 캐릭터·적·무공은 placeholder(색+텍스트)에서 출시 시점에 **단순 아이콘 + 일러스트 1장(분파 결말용)** 수준으로 확장. 풀 애니메이션 캐릭터는 정식 범위 외.
- 무협 분위기는 **색·라이팅·UI 폰트**로 표현. 외부 트윈/파티클 라이브러리 금지.

## 11. 스코프 / 제외 목록

### 11.1 정식 게임 출시 범위 (포함)
- 전투 시스템 (수싸움 양방향 매트릭스 포함)
- 무공 30~40종, 적 8~10 + 보스 1
- 재능 3종 (천무지체·카피·대종사)
- 분파 5종 (정렬·종료 분기·결말 텍스트)
- 기연 15~20종
- 한 런 15스테이지 (경로 분기 포함)
- 결말 일러스트 1장씩 (5장)
- 최소 사운드

### 11.2 출시 범위 외 (의도적으로 안 만든다)
- 메타 성장 / 영구 잠금 해제 시스템
- 다중 캐릭터 (재능 외 별도 캐릭터 클래스)
- 분파별 전용 무공 풀·전용 적 풀
- 모바일 빌드
- 멀티플레이
- 풀 음성 더빙·컷신
- 캐릭터/적 풀 애니메이션 (정지 일러스트 + 간단 트랜지션만)
- 외부 트윈/파티클 라이브러리
